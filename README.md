## 🚀 SaarthiX

> A career platform for **students, institutes, and industry**, built from scratch. Live at **[saarthix.com](https://saarthix.com)**.

- 📄 **Resume builder:** templates, a live preview, PDF and DOCX upload and parsing, ATS scoring, and PDF export
- 🧭 **Job blueprint:** a role mapped to skills and a plan
- 🎓 **Role-ready training:** trainings, applications, attendance, and certificates
- 🤖 **AI interview:** practice interviews powered by OpenAI
- 💬 **Career counselling** and a **jobs portal** with search and Google sign-in
- 🏫 **Institute enrollment** and dashboards

**Stack:** React 19 · Vite · Tailwind CSS · Spring Boot 3 (Java 17, Gradle) · MongoDB · OpenAI · JWT · Docker

## 🏢 SaarthiX Workforce

> The company product, live at **[saarthiworkforce.com](https://saarthiworkforce.com)**.

- 🗺️ **TalentX:** role blueprints, a Gantt view, generated skill topics, skill tests, and preparation analytics
- 🎤 **InterviewX:** technical assessments inside Workforce
- 📊 **Manager and HR dashboards** to watch team readiness
- 🛟 **Help and Support:** FAQs, search, an AI assistant, live chat, email, and trackable tickets

**Stack:** Next.js · NestJS · TypeScript · MongoDB · OpenAI
